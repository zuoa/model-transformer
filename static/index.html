YOLO Model Transformer

Convert YOLO .pt / .onnx to ONNX or RKNN, with conversion & quantization options.

Pipeline
ONNX → RKNN accuracy warning. A stock YOLOv8/v11 ONNX still contains the Detect head's DFL / decode and a single [1, 4+nc, 8400] output. On the board that is usually parsed as “only class 0 works”: class scores share the box INT8 scale (or a YOLOv5/objectness decoder skips real class 0). Use a head-stripped ONNX, or switch to PT → RKNN.
PT → RKNN Detect head. DFL / dist2bbox are stripped so the RKNN has the rknn_model_zoo layout: 3 scales × (box 64-ch + class nc-ch + score-sum). Set OBJ_CLASS_NUM in postprocess.h to this model’s class count (logged during conversion). Do not use a YOLOv5 decoder (5+nc with objectness) on this output.
